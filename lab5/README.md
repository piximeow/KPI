# Лабораторна робота 5: компонентна модель

Продовження lab1 (ER-модель), lab2 (вимоги до UC2), lab3 (sequence-діаграми) і lab4 (бізнес-процес). Архітектура, що реалізує UC2 + UC4, — UML Component Diagram у PlantUML.

```
lab5/
├── spec.md                       модулі, зовнішні інтеграції, межа системи, критерії
├── diagrams/
│   ├── components.puml           компонентна діаграма (текст)
│   └── components.svg            рендер з того самого тексту
├── audit.md                      аудит: відповідність lab1–lab4, межа, інтерфейси, шари, NFR, залишкові розбіжності, топ-3
├── DEFENSE.md                    точка входу: як модель зводить ланцюжок, спірні рішення
├── adr/                          рішення (MADR)
└── ai/prompts.md                 промпти, відповіді чату, топ-3 помилок AI
```
