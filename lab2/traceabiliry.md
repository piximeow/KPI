Вимога ↔ сценарій ↔ прецедент (M:N). NFR сюди не входять: вони стосуються всього UC2, а не окремого кроку.

| Вимога | S1 | S2 | S3 | S4 | UC |
|--------|----|----|----|----|----|
| REQ-01 | ✓ | ✓ |  |  | UC2 |
| REQ-02 | ✓ |  |  |  | UC2 |
| REQ-03 | ✓ |  |  |  | UC2 |
| REQ-04 |  |  |  | ✓ | UC2 |
| REQ-05 | ✓ | ✓ |  |  | UC2 |
| REQ-06 |  | ✓ |  |  | UC4 |
| REQ-07 |  | ✓ |  |  | UC4 |
| REQ-08 |  |  | ✓ |  | UC4 |
| REQ-09 |  |  | ✓ |  | UC4 |
| REQ-10 |  |  | ✓ |  | UC2 |
| REQ-11 | ✓ |  |  |  | UC3 |

Кожна вимога має сценарій, кожен сценарій має вимогу. UC1 і UC5 — поза обраним прецедентом, вимог до них тут немає.
