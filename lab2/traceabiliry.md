# Матриця трасування

Вимога ↔ сценарій ↔ прецедент (M:N: одна вимога — кілька сценаріїв, один сценарій — кілька вимог). NFR сюди не входять: вони стосуються всього UC2, перевіряються на S1–S5.

| Вимога | S1 | S2 | S3 | S4 | S5 | UC |
|--------|----|----|----|----|----|----|
| REQ-01 | ✓ |  |  |  |  | UC2, UC3 |
| REQ-02 |  |  |  | ✓ |  | UC2, UC3 |
| REQ-03 | ✓ | ✓ |  |  |  | UC2 |
| REQ-04 | ✓ | ✓ |  |  |  | UC2 |
| REQ-05 | ✓ |  |  |  |  | UC2 |
| REQ-06 | ✓ |  |  | ✓ |  | UC2 |
| REQ-07 |  |  |  | ✓ |  | UC2 |
| REQ-08 |  |  |  | ✓ |  | UC2 |
| REQ-09 |  |  |  | ✓ |  | UC2 |
| REQ-10 |  | ✓ |  |  |  | UC2, UC4 |
| REQ-11 |  | ✓ |  |  |  | UC4 |
| REQ-12 |  |  | ✓ |  |  | UC4 |
| REQ-13 |  |  | ✓ |  |  | UC4 |
| REQ-14 |  |  | ✓ |  |  | UC2, UC4 |
| REQ-15 |  |  |  |  | ✓ | UC4 |

Кожна вимога має сценарій, що перевіряє її результат; кожен сценарій має вимогу. UC1 і UC5 — поза обраним прецедентом.
