# Лабораторна робота 1: ER-модель «Онлайн-магазин»

## Домен

Я обрала онлайн-магазин, бо це зрозумілий домен, у якому є і звичайні зв'язки 1:N, і два види «багато-до-багатьох»: `category` — `product` (без власних даних, тому чистий M:N) та `order` — `product` (з `quantity` і `unit_price`, тому окрема сутність `order_item`).
